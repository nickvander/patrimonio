# Phase 3: Dashboard

**Goal:** Build the main dashboard UI with net worth tracking, account breakdowns, investment portfolio view, and exchange rate widget.

## Deliverables
- [ ] Net worth overview (total, assets vs liabilities, historical chart)
- [ ] Account breakdown (treemap by institution, type, currency, country)
- [ ] Investment portfolio (holdings table, allocation pie chart, gain/loss)
- [ ] Exchange rate widget (live USD/MXN, sparkline, history)
- [ ] Credit card utilization view
- [ ] Sync status panel
- [ ] Responsive design (web + desktop)

## Success Criteria
- Dashboard loads with real data from linked Plaid accounts
- Historical net worth chart shows data over time
- Multi-currency amounts display correctly with conversions
- Charts render smoothly with animations
